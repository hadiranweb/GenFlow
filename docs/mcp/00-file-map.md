## ستون‌های پیشنهادی برای استفاده در آینده

اگر بعداً خواستید همین جدول را به یک فایل مدیریتی دقیق‌تر تبدیل کنید، می‌توانید ستون‌های زیر را هم اضافه کنید:

| ستون | کاربرد |
|---|---|
| `status` | `draft`، `review`، `approved`، `deprecated` |
| `owner` | مسئول نوشتن یا بازبینی فایل |
| `last_updated` | تاریخ آخرین ویرایش |
| `jurisdiction` | بازار/قانون مرتبط مثل US، CA، NY، EU، IR |
| `machine_readable` | آیا فایل باید به شکل Rule/Schema قابل پردازش نوشته شود؟ |
| `requires_legal_review` | آیا نیاز به بازبینی حقوقی دارد؟ |
| `requires_hr_review` | آیا نیاز به بازبینی متخصص HR دارد؟ |
| `used_by_agent_for` | تولید پوزیشن، ممیزی، تطبیق کاندیدا، تولید گزارش و غیره |
