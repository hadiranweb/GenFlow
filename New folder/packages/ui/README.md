# GenFlow UI Components

Shared UI component library for GenFlow applications.

## Components

- `GenCard` - Card with accent line
- `GenBadge` - Small labels
- `GenButton` - Buttons
- `GenInput` - Text inputs

## Usage

```tsx
import { GenCard, GenBadge, GenButton, GenInput } from '@genflow/ui'

<GenCard>
  <GenBadge>Label</GenBadge>
  <GenButton>Click me</GenButton>
</GenCard>
```

## Installation

```bash
pnpm add @genflow/ui
```
